High-Level Architectural Topography:

The platform operates as a modular monolith / microservices-ready Node.js cluster with stateless API workers behind an Nginx reverse proxy. Redis handles transient caching, Pub/Sub channels for Socket.IO clustering, and live delivery GPS coordinates. PostgreSQL provides relational ACID integrity with PostGIS spatial indexing for high-precision society boundary containment. All background workloads (subscription cron, AI model inference batches, email queues) run via isolated async worker threads.

Domain 01

Resident Profile & Account Backend Engine

Core Identity
Functional Overview & Architecture

The Resident Profile & Account engine governs customer identity, cryptographic session management, society unit tenancy verification, and persistent address books. It enforces stateless JWT authentication coupled with Redis-backed session token blacklisting and device fingerprinting.

Backend Features & Capabilities
  • OTP-Based Passwordless Authentication: Integrates with MSG91 v5 OTP service with E.164 phone normalization, configurable rate limiting (max 3 OTP requests/10 min), and cryptographic OTP simulation bypass for automated testing.
  • Society & Flat Association Engine: Binds resident profile to verified society IDs and unit/flat numbers with multi-tenant data partitioning.
  • Saved Address Book: Multi-address support (`HOME`, `WORK`, `OTHER`) with geocoded coordinates, delivery instructions, and default address flag.
  • Account Lifecycle & GDPR Soft Deletion: Self-service account deactivation and GDPR purge endpoint that retains anonymized financial audit records while scrubbing PII.

Domain 05

Real-Time Order Management & Alarm System

Swiggy/Zomato Alert Engine
Functional Overview & Architecture

The Real-Time Order Management system features a multi-tiered order alert pipeline emulating Swiggy/Zomato merchant devices. It synchronizes WebSocket room events, high-priority Firebase push notifications with custom audio chimes, and automatic repetition loops until merchant acknowledgment.

Backend Features & Capabilities
  • WebSocket Event Multiplexing: Socket.IO server isolates vendors into dedicated rooms (`vendor_{vendor_id}`) and broadcasts instant `NEW_ORDER_ALERT` payloads upon order creation.
  • Repetitive Audio Chime Notification Loop: When a new order arrives, the server dispatches a high-priority FCM payload targeting the Android channel `order_alerts_channel` configured with sound `order_alert_chime.wav`. A background worker repeats alerts every 30s until acknowledged.
  • Order Status Transition Pipeline: Strictly validated status finite state machine: `PLACED` → `ACCEPTED` → `PREPARING` → `READY_FOR_PICKUP` → `OUT_FOR_DELIVERY` → `DELIVERED`.
  • Live Resident Status Broadcast: Every status transition triggers an instantaneous WebSocket push to the resident's client connection, updating their active tracking interface.

Domain 09

Digital Wallet & Society Credit (Khatta) Engine

Ledger & Khatta (Udhar)
Functional Overview & Architecture

The Digital Wallet & Khatta system implements a double-entry ledger architecture. It manages prepaid resident balances, instant wallet checkouts, and digitizes traditional neighborhood credit books ("Udhar / Khatta") with credit limits and automated payment reconciliation.

Backend Features & Capabilities
  • Prepaid Resident Wallet: Instant 1-click checkouts, instant refund crediting for cancelled orders, and wallet top-up via UPI/Payment Gateway.
  • Double-Entry Ledger Integrity: Every credit and debit transaction is recorded as balanced pairs in an immutable ledger table with cryptographic hash chaining to prevent tampering.
  • Merchant Khatta / Udhar Ledger: Allows trusted society residents to purchase goods on credit within pre-configured credit limits set by the vendor or society association.
  • Credit Settlement & Due Reminders: Automated calculation of outstanding balances, WhatsApp settlement reminders, and partial or full payment reconciliation.

Domain 16

Search, Geospatial & Smart Discovery Engine

Full-Text & Discovery
Functional Overview & Architecture

The Search & Smart Discovery engine indexes products, stores, and services using PostgreSQL full-text search (`tsvector` / `pg_trgm`) and geospatial bounding boxes. It delivers typo-tolerant instant search and personalized product recommendations.

Backend Features & Capabilities
  • Typo-Tolerant Trigram Search: Handles spelling variations (e.g. "biscuit", "biskit", "parle-g") across thousands of SKUs in sub-15ms query times.
  • Geospatial Store Proximity Search: Filters and sorts stores based on radial distance from resident coordinates using PostGIS spherical distance functions.
  • Collaborative Recommendation Engine: Aggregates "Frequently Bought Together" items and trending purchases specific to the resident's residential society.
  • Zero-Result Fallback & Search Telemetry: Logs search queries with zero matching products to inform vendors of unmet resident demand in their society.
